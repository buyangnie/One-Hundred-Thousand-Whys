## Reading the measurements

- Depth follows the authors’ display scale from 0 to 100. The study samples layers and reindexes them across model depth. The lesson preserves each figure’s available samples.
- Figure 51 contains a genuine **input position × depth** comparison. Every cell stores the two methods’ ranked readings for the same model activation. A token outside the ten published entries has unknown exact rank. Percent values in these cells are normalized lens readouts. The spider output bars use the next-token distribution after the forward pass.
- The figure 17 article text names Opus 4.5. The chart metadata and sonnet-4.5_jlens data file name Sonnet 4.5. The course attributes the plotted data to the chart metadata. Its numeric-grid columns index number tokens in the vocabulary at the final prompt position. The public file has eleven depths for the default operands. A stored rank of 9,999 denotes the figure's display cap. The first sampled rank-one readings for the three successive arithmetic values occur at reindexed depths 75, 83, and 100.
- Figure 18 counts the first meaningful answer after ignoring capitalization-format tokens. Some normalized display tokens have the same spelling. Figure 19 uses twelve ordered source–target pairs for each of sixteen functions. A hit means the target answer became the top answer. The source includes the per-function differences between standard and doubled swap strength.
- Figure 20 aggregates across a set of eight passages. The flexible-computation category has several question types. Its reported rate is a category-level result. A continuation can change wording while preserving its language. The course marks abbreviated continuations with an ellipsis.
- Figures 49–50 give average rubric scores across five sampled responses to each case. Lower scores mean greater honesty on these two benchmarks. The unoperated and trained conditions have published 95% confidence intervals. Ablation values come from each figure's split panel. Each benchmark tests a specific set of scenarios.
